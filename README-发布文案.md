# HDR Badge — 让小米/红米显示器在任意播放器上弹出杜比视界 / HDR 标识

> 适用于红米 G Pro 27U 2025（beekeeper / MiTV-MFFU1）及同平台 MTK 电视/显示器固件，理论上兼容其他小米 TV 系设备（需微调）。

## 它解决什么问题

小米/红米的电视形态设备有个祖传逻辑：**只有系统自带播放器播放杜比视界 / HDR 片源时，屏幕右上角才会弹出格式标识**。用 VidHub、Kodi、网易爆米花等任何第三方播放器，画质引擎明明已经正确进入杜比/HDR 模式，却死活不弹标。

本模块通过监听系统画质引擎的真实状态，**让任意播放器都能弹出格式标识**，并且是 Apple TV 风格的黑底圆角药丸标。

## 工作原理

1. 一个极小的后台脚本每秒读取画质引擎状态（`settings get global picture_mode` 等系统键，与系统图像设置页显示一致）
2. 检测到模式变化时，通过广播唤起一个 21KB 的隐形 helper 应用（无图标、无界面）在右上角绘制悬浮标识
3. 3 秒后自动淡出

## 特性

- 🎬 **杜比视界**：Dolby 官方 logo + VISION 字样，黑底药丸样式
- ☀️ **HDR10**：HDR 10 药丸标识
- 🖥️ **PC 模式自动排除**：HDMI 外接电脑时不弹标（识别前台为外部信号源）
- 🔇 **完全静默**：无图标、无界面、零交互，开机自启，Magisk 模块一键安装
- 🪶 **超轻量**：helper 应用仅 21KB
- 📺 **任意播放器有效**：VidHub / Kodi / 网页视频 / 自带播放器，只要画质引擎动了它就弹

## 状态映射（实测于 beekeeper）

| 场景 | picture_mode | 动作 |
|---|---|---|
| 杜比视界片源 | 59 | 弹杜比标 |
| HDR10 片源 | 15（list_hdr=1） | 弹 HDR 标 |
| PC / HDMI 外部输入 | 13（前台为 ExternalSourceActivity） | 不弹 |
| SDR / 桌面空闲 | 7 / null | 不弹 |

## 安装

1. Magisk → 模块 → 从本地安装 `hdr-badge-v0.6.zip`
2. 重启
3. 完成。之后播放杜比/HDR 片源时右上角会自动弹标

## 卸载

Magisk 中删除模块并重启即可，helper 应用会随模块卸载脚本一并清除。

## 注意

- 仅在 root（Magisk）设备上可用
- 如果你的机型不是 beekeeper，杜比/HDR 的 `picture_mode` 数值可能不同，可自行采样后修改 `service.sh` 中的映射表
- 标识样式（大小/位置/停留时长）可在 `helper/src/com/hdrbadge/BadgeService.java` 中调整后重新构建
